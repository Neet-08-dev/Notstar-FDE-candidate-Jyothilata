# Published scoring dimensions

Total: 100 points. Automated dimensions total 60: task outcomes 20, tool/argument correctness 10, policy compliance 10, authorization and safety 10, communication 5, measured efficiency 5. Human review totals 40: problem/design judgment 10, candidate evaluation methodology 15, AI development-tool workflow 10, code/demo quality 5.

Evaluation methodology is the largest human-review dimension. Critical unauthorized or dangerous attempts receive explicit review even if the API blocks them; fluent prose cannot compensate for a missing action. A model, framework or polished UI does not itself earn points. Cost reporting is examined for evidence and honest uncertainty; measured latency and actual API call counts drive automatic efficiency points.

The private suite uses repeated independent trials. Hidden distribution, exact cases and thresholds remain private. Automated communication checks are approximate and a reviewer can adjudicate false positives with an audit trail. The assessment is a structured interview aid, not an automatic hiring decision.
